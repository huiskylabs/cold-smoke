# 人物动作的尺子和门槛

A ruler and a gate for how the skier moves. `npm run motion` plays 17 scripted runs headless, counts the moves no human body could make
("jolts"), the places the figure passes through itself, and how the shins sit in the boots, then compares with `baseline.json` and exits 1
if anything got worse. Run it before merging any change to the figure's motion. The rest of this page is in Chinese.

## 为什么有这个

2026-11-16 的动作评审发现，动作上的几次大问题（叠弹簧、PR #44 的八字腿、实验室动作盖掉了头和雪杖的规则）都是合进去、玩了才发现的。
这套脚本把“动作好不好”里能数出来的部分数出来，改动先过它，再给人看。

## 怎么用

```
npm run motion                                            # 量现在的代码，和基线比
Q='v-mo1=b&v-medge=b&v-mo2=b&v-mo3=b' npm run motion      # 带上地址参数再量（比如打开某几个开关）
npm run motion -- --baseline                              # 改动确认合并之后，把这一轮存成新的基线
```

需要 `playwright`（和 `tools/director-render.js` 一样）。没有显卡的机器上整轮 3 到 4 分钟。同一份代码跑两次，结果完全相同。

最后会打印两段：

- **不许变差**：每分钟突变次数（合计和每个身体部位）、每个场景的突变次数、每一种穿模、小腿在靴子里侧歪多少、两膝朝向差多少。
  任何一条比基线差出容差，退出码就是 1。
- **目标**：评审定下的数字，只打印达没达到。

## 量的是什么

`record.js` 用无头浏览器跑真实的游戏（`dist/dev.html`，不出图），按脚本操作，每秒 60 帧记下 25 个关节、姿态参数和物理状态。
17 个场景共 12 分钟：键盘大中小弯、手指匀速左右、自动驾驶整条线、蘑菇地、波浪地、粉雪、跳台、连续小跳、急刹、擦树撞树、出发撑杖、团身、前后压板。

`analyze.js` 算四样：

1. **突变**。每根骨头的方向用零相位的 10 Hz 低通滤一遍，原始信号减去滤过的，剩下的超过 1.5°（位置是 6 mm）记一次，0.15 秒内算同一次，
   按身体部位换算成每分钟多少次。10 Hz 是人主动动作的上限。同一把尺量真人动作捕捉（走、跑、跳、深蹲）是每分钟 8 次左右，所以目标是 8 上下，不是 0。
2. **穿模**。身体各段当成胶囊体，量杖和腿、手和身体、两腿之间、雪板和雪面的间距，进去超过 5 mm 的帧占多少。
3. **转弯周期**。把每个弯归一成 0 到 1，列出膝、髋、上身、板刃各自的角度，以及各部位比身体倾角早晚多少毫秒。
4. **靴子里的小腿**。小腿相对雪板侧歪多少度、两个膝盖朝向差多少度。真实的滑雪靴在侧向几乎不让歪。

`gate.js` 把这一轮和 `baseline.json` 比。其余几个脚本是拆开细看用的：`land.js` 每一次落地，`poleclip.js` 雪杖穿腿，`upper.js` 上身和头，
`bob.js` 雪包上的起伏，`compare.js` 几个版本并排。它们读 `tools/motion/out/<名字>/` 下的录制。

## 这把尺的局限

- 它只管“突然一下”，不管“慢慢地错”。上身早倒、杖穿过腿，在突变数上都是流畅的，所以才同时量穿模、早晚和靴子里的角度。
- 一层重重的平滑可以把突变数刷得很好看，代价是延迟。所以改动要同时看早晚，不能只看突变数。
- 数字全过不等于看着就对。它拦得住变差，不能代替试玩。

## 改人物动作时要守的四条

1. **腿只有一个主人。** 膝永远由髋、踝和靴子规则解出来。外来的数据（实验室姿态、动捕、以后的任何动作库）只能给骨盆、上身和手臂的目标，不直接写膝、踝、脚。
2. **一个钟。** 同一个身体上的量，要么取自同一时刻，要么延迟相同。修延迟用提前量，不再加一层滤波。
3. **约束最后做一遍。** 谁最后动了关节，谁负责把靠它的规矩重查一遍：杖不穿腿、杖尖不进雪、板尖不进雪、腿不拉直、头保持水平。
4. **有尺有门槛，不叠弹簧。** 不新增平滑器；确实要加，先证明能删掉另一个。

## 现在的基线

`baseline.json` 是 `25be005`（2026-11-16 的主线）开关全部默认时的结果：突变合计 9.4 次/分钟，雪杖穿腿 36.4%，小腿侧歪 99 分位 18.2°，两膝朝向差 99 分位 46.0°。
评审的四个开关（`mo1`、`medge`、`mo2`、`mo3`，只在 `?dev` 下有效）全开时是 7.8 次/分钟、0.01%、9.6°、13.2°。
这四个开关改成默认之后，记得用 `npm run motion -- --baseline` 把基线换成新的数字，以后的改动就不能再退回去。
